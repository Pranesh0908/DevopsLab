# TaskPulse — DevOps To-Do List Application

A responsive, feature-rich web application built with HTML5, CSS3, and modern JavaScript, designed for demonstration in a DevOps CI/CD pipeline using **GitHub**, **Docker**, and **Jenkins**.

---

## 📌 Project Overview
- **Frontend Stack:** HTML5, CSS3 (Custom Design System), Vanilla JavaScript (ES6+)
- **DevOps Tools (Planned Roadmap):**
  - **Source Control:** GitHub
  - **Containerization:** Docker (lightweight Nginx container)
  - **CI/CD Automation:** Jenkins (Automated build, test, and deployment pipeline)

---

## 📁 Repository Structure
```
ToDoList/
├── index.html        # Main application layout and structure
├── style.css         # Modern styling and design system
├── app.js            # Core interactive logic and local persistence
├── .gitignore        # Git ignore rules
└── README.md         # Project documentation
```

---

## 🚀 Getting Started Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. Open `index.html` in any modern web browser or run with a local HTTP server.
